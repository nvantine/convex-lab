Input reference

LaTeX examples: w^{\top} \Sigma w, \mu^{\top} w, \sum_i w_i = 1, w \ge 0, \|w\|_1 \le 1.5, \frac{1}{2}\|Ax-b\|_2^2, \max\{x,0\}.

Declare names first. This is a documented mathematical subset, not arbitrary TeX. Unsupported notation produces an error. Single-letter and Greek names work directly; use \mathrm{long_name} for other identifiers. Literal indices start at zero; dummy indices such as i are allowed in sums.

Expression input can embed a literal LaTeX subexpression: quad_form(w, Sigma) - latex(r"\mu^{\top}w"). It follows the same whitelist and DCP checks.

Expression syntax

+, -, * (elementwise), /, @ (matrix product), **2, and literal indexing such as w[0] or w[0:2].

sum(x), sum_squares(x), square(x), quad_form(w, Sigma), norm(x, 1), norm(x, 2), norm(x, 'inf'), abs(x), pos(x), max(x), maximum(x, y), hstack([x, y]), vstack([x, y]). sum and max accept axis=0 or axis=1.

A parameter is fixed for one solve. A variable is optimized. Promoting a parameter can introduce products of variables; the DCP check explains whether the new expression is supported.

Shape [] means scalar. Indices start at zero. A covariance parameter used in quad_form should have domain PSD; its supplied matrix is validated.
